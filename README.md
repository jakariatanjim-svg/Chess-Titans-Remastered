# Chess Titans Remastered

A native Windows desktop chess game inspired by the calm, tactile presentation of Windows Vista / Windows 7 Chess Titans. The initial release is a local two-player game; there is deliberately no computer opponent or chess engine yet.

## Run it

1. Install **Godot 4.7.2** (standard, non-.NET build).
2. Open this folder in Godot and press **F6/F5**, or launch the exported Windows package.
3. Choose **New Local Game**. Select a piece and destination, or drag it. Right-drag or middle-drag to orbit; the wheel zooms; double-click the board to reset the camera. Escape opens the menu and F11 toggles fullscreen.

All board and chess-piece geometry is generated by the project’s own GDScript model builders. The knight is a custom extruded relief; the other pieces use lathed profiles with collars, bands, crowns, mitre details, and distinct silhouettes. Interface sound effects are original synthesized WAVs; `tools/generate_sfx.py` recreates them. No third-party art or sound is bundled.

## Project layout

- `scripts/chess_rules.gd` — rules-only position manager: legal move generation, check, mate, stalemate, castling, en passant, promotion, FEN, repetition, 50-move and insufficient-material draws, undo, and position timeline. It does **not** search for or evaluate moves.
- `scripts/board_factory.gd`, `scripts/piece_factory.gd` — board, table, piece geometry, materials, and selection markers.
- `scripts/game_controller.gd`, `scripts/game_ui.gd` — input, animation, camera, local match flow, UI, settings, and sound.
- `tests/test_chess_rules.gd` — headless regression suite for core chess rules.
- `export_presets.cfg` — Windows x64 desktop export preset.
- `.github/workflows/windows-artifact.yml` — artifact-only test build (manual and pull-request builds; it never tags or publishes a release).
- `.github/workflows/windows-release.yml` — versioned Windows release with a tag and auto-generated GitHub release notes.

## Build locally

Install Godot 4.7.2 and its matching export templates, then run:

```sh
godot --headless --editor --path . --quit
godot --headless --path . --script res://tests/test_chess_rules.gd
godot --headless --path . --export-release "Windows Desktop" build/Chess-Titans-Remastered.exe
```

The Windows export is a standalone `.exe` plus its `.pck` resource pack. Keep both files together when launching. The workflow zips them with a short `README.txt` for convenient distribution. Models and textures will dominate package size as the art is expanded; the current procedural assets keep the build self-contained.

## GitHub build and release system

Both workflows use **Godot 4.7.2** and cache Godot/export-template setup through `chickensoft-games/setup-godot`.

### Windows — Test Build

Run it from **Actions → Windows — Test Build → Run workflow**, or open a pull request. It runs the rules regression suite, exports and uploads a downloadable Windows ZIP artifact. It creates no tag and no GitHub Release. Its version label previews the next published version.

### Windows — Release

Run **Actions → Windows — Release → Run workflow**. Leave **Version override** empty for the next version, or enter a version such as `1.3` or `2.0`. The sequence advances `1.0 → 1.1 → … → 1.9 → 2.0`; it derives the next version from the highest existing `vX.Y` tag, so a manual override does not reset future automatic versions. The workflow exports the Windows package, creates the `vX.Y` tag at the selected commit, and publishes a GitHub Release with automatically generated release notes and the ZIP asset.

For safety, dispatching a release from a non-default branch requires enabling the confirmation input. Test builds work from any branch. Releases use the repository’s `GITHUB_TOKEN`; no signing secrets or third-party credentials are required.

## Future Stockfish integration

The rules layer exports FEN and is isolated from presentation. A later desktop integration can launch the explicitly requested Stockfish 19 binary over UCI without changing board rendering or the local rules API. No engine binary or AI opponent is included in this version.
